# Mclarans Telecommunications

Company website for Mclarans Telecommunications — fiber broadband, mobile,
and enterprise connectivity services.

Built with [React](https://react.dev/) + [Vite](https://vite.dev/) and
[React Router](https://reactrouter.com/).

## Pages

- **Home** — hero, service highlights, stats, and promotions
- **Services** — fiber broadband, mobile, enterprise, cloud PBX, IoT, security
- **Plans** — fiber and mobile pricing tiers
- **About** — mission, values, and company timeline
- **Contact** — contact details and inquiry form

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                        |
| ----------------- | ---------------------------------- |
| `npm run dev`     | Start the development server       |
| `npm run build`   | Build for production into `dist/`  |
| `npm run preview` | Preview the production build       |
| `npm run lint`    | Lint the codebase with oxlint      |
